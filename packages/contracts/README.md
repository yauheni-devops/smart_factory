# Контракты

JSON Schema — договор между сервисами. Catalog, telemetry и ktp должны понимать одни и те же поля.

Пока схемы описывают смысл. Валидацию на входе подключим, когда появится приём данных.

`site.schema.json` описывает площадки, `equipment.schema.json` — единицу оборудования и её план обслуживания. Источник начальных данных завода остаётся в `data/plant.yaml`; история показаний счётчиков и фактически выполненных работ будет храниться в PostgreSQL на следующем этапе.

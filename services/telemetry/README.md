# Telemetry

Приём показаний датчиков. Список площадок **не хранит** — спрашивает catalog (порт 8081).
История пока в памяти процесса: перезапуск uvicorn обнуляет данные. PostgreSQL — следующий этап.

Порт: 8082.

Страницы `/ui`, `/monitoring`, `/production`, `/alerts`, `/documents`, `/reports`, их данные в `/ui/*`, ресурсы `/assets/*` и чтение `/readings` требуют сеанс входа. При первом открытии главной страницы браузер переходит на форму сервиса ПТО (`8086/login?next=home`); после входа возвращается на главную. Cookie действует для одного имени хоста на разных портах: используйте везде либо `localhost`, либо `127.0.0.1`. Проверка сеанса выполняется через `MAINTENANCE_AUTH_URL` (по умолчанию `http://127.0.0.1:8086`). Для работы интерфейса сначала запустите maintenance. Запись учебных показаний симулятором через `POST /readings`, `/health` и `/metrics` остаются отдельными техническими маршрутами.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/health` | жив ли процесс |
| POST | `/readings` | записать одно показание |
| GET | `/readings` | последние показания |
| GET | `/ui` | Стартовая страница с переходами в разделы системы |
| GET | `/monitoring` | HTML-схема с датчиками |
| GET | `/production` | Отдельная страница выпуска план/факт |
| GET | `/alerts` | Отдельная страница аварий и предупреждений по телеметрии |
| GET | `/documents` | Начальная структура раздела документов оборудования |
| GET | `/reports` | Снимок последних показаний с выгрузкой CSV для Excel |
| GET | `/ui/data` | JSON для этого экрана |
| GET | `/ui/production` | Сводка план/факт активных заявок сервиса выпуска |

Страница выпуска показывает активные заявки `services/production` (порт 8083), а страница предупреждений проверяет полноту и свежесть данных датчиков. Предупреждения по технологическим пределам появятся после настройки утверждённых уставок; сейчас они не вычисляются.

В разделе документов пока нет загрузки или хранения файлов. Раздел отчётов формирует снимок последних показаний, а не историю за период; CSV содержит время показаний и время формирования сводки по Москве (МСК). В учебном окружении источником показаний служит симулятор.

Резервные цеха (`status: reserved`) показания не принимают.

## Запуск на lab (второе окно, catalog уже на 8081)

Из корня, тот же `.venv`:

```bash
source ~/smart_factory/.venv/bin/activate
python -m pip install -r ~/smart_factory/services/telemetry/requirements.txt
cd ~/smart_factory/services/telemetry
uvicorn app.main:app --host 0.0.0.0 --port 8082
```

Проверка:

```bash
curl http://127.0.0.1:8082/health

curl -X POST http://127.0.0.1:8082/readings \
  -H "Content-Type: application/json" \
  -d '{"site_id":"workshop-dry-mix-1","metric":"power_kw","value":120.5,"unit":"kW"}'
```

Откройте `http://127.0.0.1:8082/ui` и войдите через форму. Прямой запрос к `/readings/latest` без сеанса вернёт `401`.

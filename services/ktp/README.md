# KTP

Живое состояние комплектной трансформаторной подстанции:
выключатели ВН/НН, норма/авария, позже U/I/P и температура масла.

Сама КТП и кого она питает — в catalog. Этот сервис не хранит список цехов,
он хранит **текущее состояние** и (позже) учебные команды контроля.

Порт: 8084.
Контракт: `packages/contracts/schemas/ktp-state.schema.json`.

Дистанционное отключение — только учебный API, не реальная ячейка.

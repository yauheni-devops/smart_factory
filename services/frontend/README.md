# Frontend

Статические страницы интерфейса завода. NGINX работает от непривилегированного
пользователя, раздаёт HTML и схему, а запросы к API телеметрии проксирует по
тому же origin. Это позволяет браузеру обращаться к frontend без настройки CORS.

Главная содержит переходы в мониторинг, обслуживание, выпуск, предупреждения,
документы оборудования и отчёты. Документы содержат руководства Kinco FV100,
ABB ACS310 и паспорт розеток ABB Levit с просмотром и скачиванием PDF после входа.
Оригиналы находятся в `data/equipment-documents` и копируются в образ при сборке;
загрузки новых файлов через сайт пока нет. Отчёты показывают последние показания
и позволяют скачать CSV для Excel.

NGINX проверяет сеанс через `/session` сервиса maintenance перед выдачей страниц и данных. Если сеанса нет, браузер переходит на общую форму входа, а затем возвращается на `/ui`.

В Compose NGINX обращается к API по DNS-именам сервисов во внутренней Docker-сети. API не публикуются на порты хоста. Команды запуска и проверки приведены в [`../../docs/container-runbook.md`](../../docs/container-runbook.md).

Копии HTML в `services/frontend/static` и `services/telemetry/app/static`
сохраняют старые локальные сценарии запуска; Compose использует frontend-копию.

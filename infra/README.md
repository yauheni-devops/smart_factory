# Инфраструктура

Compose-конфигурация хранится в корне проекта (`compose.yaml`). Она запускает
шесть сервисов приложения в закрытой Docker-сети и публикует frontend на
`127.0.0.1:8080`. API не открывают порты на хосте.

Команды запуска, проверки и остановки: [`../docs/container-runbook.md`](../docs/container-runbook.md).

Prometheus и Grafana запускаются дополнительным профилем `observability`.
Конфигурация Prometheus, источник Grafana и панели находятся в
`infra/observability/` и собирают метрики по внутренним DNS-именам Compose.

Отдельный сервис `ktp` пока не реализован. PostgreSQL, Terraform, Kubernetes
и облачные ресурсы относятся к следующим учебным этапам; в текущем контейнерном
стенде ПТО продолжает использовать SQLite.

# Архитектура

Микросервисы здесь — это границы ответственности, не «много GitHub».
Один репозиторий, несколько процессов. На Linux lab каждый сервис слушает свой порт.

```
                    ┌─────────────┐
                    │   catalog   │  площадки, КТП, маршруты
                    │    :8081    │
                    └──────┬──────┘
                           │ читают каталог
          ┌────────────────┼────────────────┐
          ▼                ▼                ▼
   ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
   │  telemetry  │  │    ktp      │  │ production  │
   │    :8082    │  │    :8084    │  │    :8083    │
   └──────▲──────┘  └──────▲──────┘  └──────▲──────┘
          │                │                │
          └────────┬───────┴────────┬───────┘
                   ▼                ▼
            ┌─────────────┐  PostgreSQL / Redis — этап 2
            │  simulator  │
            │    :8085    │
            └─────────────┘
```

## Зачем резать так

| Сервис | Вопрос, на который он отвечает | Почему не в одном процессе |
|---|---|---|
| catalog | Что есть на заводе? | Меняется редко, все остальные на это ссылаются |
| telemetry | Что показывают датчики? | Поток данных, другая нагрузка |
| ktp | Живо ли КТП, включён ли выключатель? | Энергетика и безопасность, не «ещё один датчик» |
| production | Что должны выпустить и что уже выпустили? | Документооборот заявок |
| simulator | Откуда берутся учебные события? | Не путать имитацию с «настоящим» API |

Позже появится Nginx (вход снаружи) и Grafana (смотреть). Это не отдельные бизнес-сервисы.

## Как сервисы разговаривают

Сейчас catalog отдаёт JSON по HTTP. Telemetry при POST спрашивает catalog: «есть ли такая площадка?». Simulator раз в 5 секунд читает активные площадки и пишет показания в telemetry.

Дальше (не сейчас):

- ktp держит текущее состояние выключателей;
- production хранит заявки в PostgreSQL;
- Redis / очередь между сервисами.

Контракт сообщений лежит в `packages/contracts/schemas`. Язык сервиса можно сменить — схема останется.

## Что ещё не делаем

Нет Docker Compose в бою, нет Kubernetes, нет общей базы.
